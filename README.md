# 六合智析 · 学术统计演示版（云端台账）

固定链接：https://ronald9527.github.io/

## 数据在哪
- `data.json` —— **云端权威台账**：开奖记录 + 2026 对照表 + 命中判定，由元宝在对话中维护并推送
- 页面启动自动以 `no-store` 拉取 `data.json`，任何设备打开链接看到同一份数据，刷新即最新
- 本机 localStorage 仅作离线兜底；对话里发的开奖号由元宝更新云端，不需要你上传任何文件

## 目录
- `rules-2026.json` 2026 马年完整对照表（v1.1，两套属性体系并存）
- `data/records-first5.json` 首批 5 期开奖记录
- `data/stats-first5.json` 描述性统计
- `data/ledger.json` 台账快照
- `data/reference/` 未核验的外部参考样本（单列，不并入主台账）
- `docs/` 核对报告与统计说明
