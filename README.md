# 六合智析 · 学术统计演示版（GitHub Pages 仓库）

> 静态仓库：GitHub Pages 从默认分支根目录发布。
> **页面内容由站点文件决定；开奖与回溯数据由 `data.json` 决定，二者都由元宝在对话框里维护，仓库所有者无需上传任何文件。**

## 目录

| 文件 | 作用 |
|---|---|
| `index.html` | 单文件页面（CSS/JS/图标内联），6 个主 Tab、14 个模块卡片、6+1 录入、历史战绩、逐期回溯 |
| `data.json` | **线上台账**：`records`（开奖）+ `hits`（逐模块命中判定）。页面启动和点「🔄 同步最新台账」时读取 |
| `manifest.json` / `sw.js` / `icon-*.png` | PWA 可选增强，缺了页面照常运行 |
| `.nojekyll` | 让 GitHub Pages 原样发布，不走 Jekyll |
| `.gitignore` | 忽略项 |

## 更新方式

1. **用户**：在对话框发 `期号 | 日期 | 6正码 | 特码`，或提出改文案 / 补规则 / 加模块。
2. **元宝**：改好 `data.json`（必要时也改 `index.html`），通过 GitHub Contents API 提交到本仓库。
3. **GitHub Pages**：自动重建（约 1 分钟）。
4. **用户**：刷新页面或点「🔄 同步最新台账」即看到最新，**不上传、不重装**。

`data.json` 请求带 `cache: no-store`，不受 CDN 缓存影响。

开奖为随机事件，历史频率不具外推预测力。本页**不预测号码、不提供投注建议、不接支付与赔率**，仅供本地学术统计与口径核对，不传播、不用于投注。
