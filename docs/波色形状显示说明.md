# 历史开奖 · 号码带生肖（同球显示）

> 已上线：https://ronald9527.github.io/ → 「历史开奖」

## 每颗球长这样

**一个彩色圆圈里同时放号码和它对应的 2026 生肖**：

```
   ●────●        ●────●
   │ 14 │        │ 20 │  ← 金边＝特码
   │ 蛇 │        │ 猪 │
   ●────●        ●────●
  蓝圈(蓝波)    蓝圈(蓝波)
```

- **圈内上行＝号码，下行＝该号码对应的生肖**（不再是圈外小字）
- **圈的颜色＝波色**：● 红波红圈 / ● 蓝波蓝圈 / ● 绿波绿圈，全部统一圆形
- 6 个正码后 **`=`** 分隔，后面那颗是**特码**：仍是圆，多一圈金色描边，圈内生肖**金色加粗**
- 每行下方保留两行汇总：`波色 红N · 蓝N · 绿N` ＋ `生肖 马N · 蛇N …`（都含特码）
- 长按/悬停可看 `号码 · 波色 · 生肖`
- 图例：`● 红波  ● 蓝波  ● 绿波  = 之后为特码（金边）  圈内下行＝生肖`
