# 历史开奖 · 页面改版说明

> 固定链接：https://ronald9527.github.io/ → Tab「历史开奖」

## 改了什么

**① 改名**：Tab、页面标题、录入提示、CSS 注释、全部文档统一为 **历史开奖**。

**② 从 5 列表格 → 卡片列表**（原来窄屏挤成 5 列，现在一期一张卡）

| 区块 | 现在 |
|---|---|
| 头部 | 标题「历史开奖」+ `共 137 期 · 待补 31 期` 徽标 |
| 图例 | 淡底圆角条：●红波 ●蓝波 ●绿波 · `= 之后为特码（金边）` · `圈内下行＝生肖` |
| 工具 | 筛选框（期号 / 日期 / 号码即时过滤）+「清除」 |
| 计数 | `显示 137 / 共 137 期` · `最新在前 · 最后一位＝特码` |
| 卡片 | 期号粗体 · 日期淡 · **最新**标签（仅首条）· `0/14` 徽标 · 右上角淡灰 `×`（点删除带确认） |
| 号码区 | 淡底圆角容器，波色圈圈 + 圈内生肖，`=` 后特码金边 |
| 汇总 | 两个轻量 chip：`波色 红3·蓝3·绿1`、`生肖 …` |
| 细节 | 卡片 hover 微阴影、最新一期淡蓝高亮、手机竖屏自动换行 |

## 没动什么

- 137 期云端数据、期号 / 日期 / 7 球、最后一位＝特码口径
- 波色圈圈（统一圆形、只靠颜色区分）、圈内生肖、特码金边
- 波色小结与生肖汇总的**文字内容**（只换了外壳样式）
- 云端 `data.json` 仍是唯一权威源，刷新即最新；不上传、不装 App

## 新增的小功能

**筛选**：在框里输 `2026321`、`11-17`、`14` 都能即时过滤，命中数实时显示；点「清除」回到全部。删除前加了二次确认，避免误触。
