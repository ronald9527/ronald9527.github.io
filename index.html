复述与核对要点

1. 版本标识冲突：标题 v3.3 / 页内 v3.4 / 页脚 v3.0 · 数据统计演示。
2. 名称冲突：资料与链接为「六合智析 / liuhe-zhixi」，需求文字写作「竞彩智析」。
3. 「候选池（两波+三头+七尾 . +七肖补充）」含多余分隔符「.」。
4. 组合口径未定义：「4 组」「10 组」「8/10/12 码三中三」「6 正码中 3 即中」未给出基础集合与组合生成方式。
5. 核心缺失：仅 UI 标签 + 免责声明，缺随机变量定义、样本空间、模块生成算法、命中判定、回溯统计口径与基准对照，不可复现，尚不构成学术模型。
6. 逻辑冲突：「开奖为随机事件」与「给出下一期会开出的号码 / 本期推荐」互斥。
7. 「自动同步」的数据来源、样本区间与更新机制未定义。

关于「下一期号码」

独立随机事件下，历史频率不具外推预测力；任何声称可由历史统计给出「下一期会开出的号码」在学术上不成立。本演示只提供描述性统计与回溯校验，不预测、不推荐、不涉投注。
